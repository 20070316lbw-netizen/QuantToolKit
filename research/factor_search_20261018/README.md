# 量价因子探索: 隔夜反转

本轮找到了值得继续研究的候选 `overnight_reversal_63`
全样本平均 Rank IC 高于两个固定动量基准, 但未证明它在新样本上不劣于 12-1 动量
尤其是 2023-2024 年, 它的方向失效, 明显落后于 12-1 动量
这是一份研究记录, 未加入正式因子接口

## 因子是什么

```text
adjusted_open[t] = open[t] * adj_close[t] / close[t]
overnight[t] = log(adjusted_open[t] / adj_close[t-1])
factor[t] = -sum(overnight[t-62:t+1])
```

累计过去 63 个交易日的隔夜收益, 然后取负值
过去隔夜涨得越多, 因子越低; 过去隔夜跌得越多, 因子越高
假设是部分隔夜涨跌会在后续发生回吐, 机制尚未证实
信号只使用截至当天收盘的行情, 价格列为正数, 需要至少 64 条连续有效价格记录
volume 为 0 的补齐日不作为真实隔夜交易, 对应窗口输出缺失

复权开盘价和复权前收盘价保持同一口径, 避免把拆股或分红调整机械地计入隔夜收益
日内对数收益与隔夜对数收益之和等于当天复权收盘到收盘的对数收益
合成拆股数据与真实数据都已检查该公式

背景阅读: [纽约联储的隔夜收益研究](https://www.newyorkfed.org/research/staff_reports/sr917)
该研究考察股指期货的隔夜现象, 不能用来证明本实验的个股截面因子有效

## 比较口径

- 数据库只读, 本次行情覆盖 2016-01-04 至 2026-10-09, 共 503 个 ticker
- 主标签为 `adj_close[t+22] / adj_close[t+1] - 1`, 对应下一交易日收盘入场后持有 21 个交易日
- `mom_63 = log(adj_close[t] / adj_close[t-63])`
- `mom_231_skip_21 = log(adj_close[t-21] / adj_close[t-252])`
- 八个因子共用同一日期与证券掩码, 不使用各自更有利的样本
- 要求至少 252 条历史价格变化, 最近 64 条记录成交量均大于 0, 标签进出场记录也有成交量
- 每个截面平均约 469 至 498 只股票, 有效截面至少 100 只
- 每个研究区间末尾剔除标签退出日跨越区间边界的信号
- Rank IC 为当天因子与未来简单收益的 Spearman 相关, 数值越大越好
- 未来收益标签重叠, 不把它们复利为策略净值, 不作成交或费用假设

## 实际结果

主标签下的日均 Rank IC:

| 区间 | 63 日动量 | 12-1 动量 | 隔夜反转 |
| --- | ---: | ---: | ---: |
| 2017-2020 | -0.00630 | 0.00177 | 0.02113 |
| 2021-2022 | -0.01643 | -0.00718 | 0.02023 |
| 2023-2024 | -0.01707 | 0.04763 | -0.00928 |
| 2025 至末个完整标签 | -0.02518 | 0.01793 | 0.05084 |

不做区间边界剔除的全期描述统计, 使用 2017-01-03 至 2026-09-09 的 2434 个完整标签截面:

| 因子 | 日均 Rank IC |
| --- | ---: |
| 63 日动量 | -0.01218 |
| 12-1 动量 | 0.01009 |
| 隔夜反转 | 0.01903 |

全期数据参与了探索, 不能把这张表当作样本外成绩
按信号所属年份统计, 隔夜反转在 10 个年份中只有 5 年的平均 Rank IC 高于 12-1 动量
2026 年只覆盖部分年份

隔夜反转减去 12-1 动量的日均 Rank IC 差值, 使用 63 日移动区块自助法进行 2000 次配对重采样:

| 区间 | 平均差值 | 95% 区间 |
| --- | ---: | --- |
| 2023-2024 | -0.05692 | [-0.12165, 0.00092] |
| 2025 至末个完整标签 | 0.03291 | [-0.09649, 0.17145] |

区间很宽, 没有预设不劣界值, 也没有校正探索选择偏差, 不能据此宣布统计上不劣
五分位未来收益也没有在所有区间呈现单调顺序, 见 `followup_overnight/quintiles.csv`

## 稳健性与失败条件

- 2023-2024 年失效, 不是每个市场阶段都有效
- 2025+ 的 21 日 Rank IC 在按细分行业去均值后从 0.05084 降至 0.02665, 部分信号与行业有关
- 同期按行业去均值的 12-1 动量为 0.02103, 差距已经很小
- 5 日标签上, 两个后续区间都没有超过 12-1 动量
- 63 日标签上, 两个后续区间也都没有超过 12-1 动量
- 与 12-1 动量的平均截面秩相关约为 -0.22 至 -0.26, 不是完全重复的排序
- 当前成分股向历史回溯, 存在存活与历史成员偏差, 所有比较都只对这个股票池成立
- 原始行情提供者的复权质量未在本轮逐笔审计

## 保留完整探索经过

`protocol.json` 在查看本轮后续区间指标前写入, 固定了六个候选, 两个基准与窗口方向
候选包括日内强度, 隔夜反转, 收盘位置, 量价背离, 低波动和路径平滑动量

原始规则只按 2021-2022 年平均 Rank IC 选一个, 选中了低波动
它在 2023-2024 和 2025+ 的 Rank IC 分别为 -0.04619 与 -0.07648, 首轮失败
这个结果保留在本目录的 `comparison.csv` 中

看到首轮失败后, 才追加检查了隔夜反转
选择依据是它在最初两个研究区间中均为正, 且两者的较小值在候选中最高
没有改变其窗口或方向, 也没有查看其余候选在后续区间的指标后再次替换
完整后续结果在 `followup_overnight/` 中, 不能宣称是独立留出确认
即使没有这次追加探索, 也无法保证这些历史日期从未用于此前其他实验

结论保持为: 找到了具体的研究候选, 尚未达到可靠确认不劣于动量的程度

## 复现与检查

在仓库根目录运行:

```bash
uv run python research/factor_search_20261018/experiment.py
uv run python research/factor_search_20261018/followup.py
uv run pytest research/factor_search_20261018/test_experiment.py -q
```
